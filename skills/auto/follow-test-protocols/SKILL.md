---
name: follow-test-protocols
description: Adhere to testing protocols to ensure thorough coverage and compliance with requirements before submission.
---
- Confirm that you have preserved the original testing files and only modified or created new tests as necessary.
- Always document changes in a changelog as specified in the project guidelines.
- Implement at least one test per bug fix in dedicated regression test files.
- Verify that all functions and methods have corresponding tests that cover expected behavior and edge cases.
- Review the test structure and naming conventions to ensure clarity and compliance.
- Execute all tests after making changes to confirm no new issues were introduced.
