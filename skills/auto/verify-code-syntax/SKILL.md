---
name: verify-code-syntax
description: Utilize this skill to validate the syntax of your code before running tests or executing it.
---
- Use linters or syntax checkers to identify syntax errors during development.
- Run `python -m py_compile <filename>` on new or modified files to catch syntax issues early.
- Ensure proper testing of any string operations, paying attention to escaped characters.
- Insert print statements or logging to isolate the exact line causing syntax errors.
- Break down complex lines into simpler statements to identify syntax issues more easily.
- Frequently run your code in small increments to catch errors sooner.
